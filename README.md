# Crosshair Overlay

Прозрачный оверлей с прицелом поверх любой игры на Windows.
Собственный редактор прицела, тёмная и светлая темы, глобальные горячие клавиши, трей.

![demo](demo.gif)

## Возможности

- 🎯 Прозрачный оверлей с прицелом в центре экрана
- 🎨 Редактор: тип, длина, отступ, толщина, точка, цвета, обводка
- 💾 Свой набор прицелов, импорт/экспорт в JSON
- 🌗 Тёмная и приглушённая светлая тема
- ⌨️ Глобальные горячие клавиши (F8 / F9 / F10 по умолчанию, настраиваются)
- 📌 Трей в системном лотке, сворачивание по крестику
- 🖱️ ПКМ по прицелу в списке — переименовать, дублировать, удалить

## Установка

### 1. Клонировать

```bash
git clone https://github.com/USERNAME/crosshair-overlay.git
cd crosshair-overlay
```

### 2. Установить зависимости (только для трея)

```bash
python -m pip install -r requirements.txt
```

Без них приложение тоже запустится — просто не будет иконки в трее.

### 3. Запустить

```bash
python crosshair.py
```

## Сборка в .exe

```bash
python -m pip install pyinstaller
python -m PyInstaller --noconsole --onefile --name Crosshair crosshair.py
```

Готовый файл появится в `dist/Crosshair.exe`.

## Использование

- **ЛКМ по прицелу** в списке — выбрать
- **ПКМ по прицелу** — меню (переименовать / дублировать / удалить)
- **Двойной клик** — переименовать
- **F8** — показать/скрыть оверлей
- **F9 / F10** — следующий / предыдущий прицел
- **Крестик окна** — свернуть в трей

## Что важно для оверлея

Игра должна быть в режиме **«Оконный безрамочный» (Borderless Windowed)**.
Поверх полноэкранного эксклюзивного режима оверлей не показывается —
это ограничение Windows, а не приложения.
